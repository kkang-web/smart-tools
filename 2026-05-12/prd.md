# PRD — 사내 안전운전 캠페인 사이트

**문서 버전:** 1.0  
**작성일:** 2026-05-12  
**연관 파일:** `안전운전_캠페인.html`  
**연관 BRD:** `brd.md`

---

## 1. 제품 개요

단일 HTML 파일(`안전운전_캠페인.html`)로 구성된 1페이지 캠페인 사이트.  
백엔드·빌드 없이 브라우저에서 직접 열어 동작한다.

---

## 2. 페이지 구조

총 6개 섹션이 위에서 아래로 순서대로 배치된다.

| 순서 | 섹션 | 역할 |
|---|---|---|
| 1 | `.topbar` | 로고, 오늘 날짜(JS 자동), 캠페인 연도 |
| 2 | `.hero` | 슬로건, 서브 카피, 도로 점선 장식 |
| 3 | `.messages` | 핵심 메시지 3종 카드 |
| 4 | `.period` | 캠페인 기간 배너 |
| 5 | `.qr-section` | QR코드 자리 + 서약 버튼 |
| 6 | `footer` | 부서명, 연락처, 저작권 |

## 3. 콘텐츠 명세

|---|---|---|---|
| 01 | 규정 속도 준수 | 속도 관리 | 파랑 `#0057b8` |
| 02 | 운전 중 휴대폰 금지 | 집중 운전 | 주황 `#f47920` |
| 03 | 졸음운전 즉시 대응 | 피로 관리 | 파랑 `#0057b8` |

주관 부서 표시: 섹션 타이틀 하단 뱃지 → `주관 · AI 데이터처`

## 4. 디자인 사양

### 4-1. 컬러 팔레트

| 변수 | 값 | 용도 |
|---|---|---|
| `--green` (실제: 파랑) | `#0057b8` | 주 브랜드 컬러, 링크, 카드 포인트 |
| `--green-d` | `#003d82` | 파랑 hover, 짙은 강조 |
| `--green-l` | `#e8f1fc` | 카드 배경, 뱃지 배경 |
| `--orange` | `#f47920` | 슬로건 강조, 버튼, 포인트 |
| `--orange-d` | `#c75500` | 주황 hover |
| `--navy` | `#0b1f3a` | 헤더·히어로·기간 배너 배경 |
| `--navy-m` | `#0e2d6b` | 히어로 그라데이션 중간값 |

> ⚠️ CSS 변수명이 `--green`으로 남아 있으나 실제 값은 파랑임. 다음 버전에서 변수명 정리 권장.

### 4-2. 타이포그래피

| 역할 | 폰트 | 크기 | 굵기 |
|---|---|---|---|
| 기본 | Noto Sans KR (CDN) → Malgun Gothic | 13~15px | 400 |
| 슬로건 | 상동 | `clamp(32px, 5vw, 56px)` | 900 |
| 섹션 타이틀 | 상동 | 26px | 700 |
| 카드 제목 | 상동 | 13px | 600 |

### 4-3. 레이아웃

- 전체 너비: 100% (반응형)
- 핵심 메시지 카드: `grid-template-columns: repeat(3, 1fr)` → 700px 이하 `1fr`
- 캠페인 기간 칩: `flex-wrap: wrap`

### 4-4. 반응형 브레이크포인트

```css
@media (max-width: 700px) {
  /* 패딩 축소, 카드 1열, 폰트 크기 유지 */
}
```

## 5. 기술 사양

- **구조:** 단일 HTML 파일 (CSS·JS 인라인 포함)
- **외부 의존:** Google Fonts CDN (인터넷 연결 필요)
- **JS:** 오늘 날짜 자동 표시 (`Date` API, 인라인 `<script>`)
- **인터랙션:** 카드 hover 시 `translateY(-4px)` + `box-shadow` 전환
