# PRD — 한국도로공사 교통량 모니터링 대시보드

> **대상 독자**: 이 파일을 처음 보는 Claude Code 또는 개발자  
> **최종 수정**: 2026-05-11  
> **구현 파일**: `traffic_dashboard.html` (단일 파일, 서버 불필요)

---

## 1. 제품 개요

한국도로공사(Korea Expressway Corporation)의 고속도로 5개 노선에 대해 **2026-04-01 ~ 2026-04-07 (7일)** 기간의 교통량·속도 데이터를 시각화하는 **정적 HTML 대시보드**다.

- 백엔드·서버·DB 없음 — 모든 데이터가 HTML 내부 JS 변수(`RAW`)에 하드코딩됨
- 인터넷 연결 필요 (Chart.js, chartjs-plugin-datalabels CDN 로드)
- 브라우저에서 파일을 직접 열면 즉시 동작

## 3. 핵심 기능 목록

### 3-1. 필터 (Filter Bar)

모든 필터는 변경 즉시 전체 화면을 재렌더링(`render()` 호출)한다.

| 필터 ID | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `selRoute` | `<select>` | `ALL` | 전체 또는 특정 노선 1개 선택 |
| `selDate` | `<select>` | `ALL` | 전체 또는 특정 날짜 1일 선택 |
| `sHMin` / `sHMax` | `<input range>` | 0 / 23 | 조회 시간대 범위 (0~23시) |
| `sCong` | `<input range>` | 60 | 혼잡 판단 기준 속도 (km/h), 20~80 범위 |

**제약 조건**
- `sHMin` ≤ `sHMax` 항상 유지 (슬라이더 교차 방지 로직 내장)

---

### 3-2. KPI 카드 (4개)

| 카드 | 계산 방법 | 단위 |
|---|---|---|
| 총 교통량 (`k1`) | 필터된 레코드의 `vol` 합산 | 대 |
| 평균 속도 (`k2`) | 필터된 레코드의 `spd` 평균 | km/h |
| 혼잡 시간대 (`k3`) | `spd < st.cong` 인 레코드 수 | 건 |
| 최대 교통량 (`k4`) | `vol` 최대인 단일 레코드 | 대 (노선·시간 표시) |

**평균 속도 상태 문구 기준**
- ≥ 80 km/h → "원활"
- ≥ 60 km/h → "서행"
- < 60 km/h → "정체"

---

### 3-3. 차트 (Chart.js 기반)

#### ① 시간대별 교통량 추이 (`cHourly`) — 선형 차트
- X축: 0시~23시
- Y축: 교통량(대)
- 데이터셋: 선택된 날짜별 1개 선 (ALL 선택 시 7개 선)
- 데이터 레이블: 단일 날짜일 때 매 포인트, 복수 날짜일 때 3시간 간격(`h % 3 === 0`)
- 필터 범위 밖 시간대는 `null`로 처리 (선 단절)

#### ② 요일별 총 교통량 (`cDaily`) — 막대 차트
- X축: 7개 날짜
- Y축: 해당 날짜 전체 `vol` 합산
- 색상 규칙:
  - 주말(토·일, index 3·4): 노란색(`#f59e0b`)
  - 최대값 날짜: 빨간색(`#ef4444`)
  - 나머지: 파란색(`#3b82f6`)

#### ③ 노선별 시간대 평균 교통량 (`cRoute`) — 그룹 막대 차트
- X축: 0시~23시
- Y축: 해당 시간대 평균 `vol` (선택 날짜 기준 평균)
- 데이터셋: 선택된 노선별 1개 막대 그룹 (ALL 시 5개 노선)

---

### 3-4. 정체 Top 5 테이블 (`tTop5`)

- 필터된 데이터를 `spd` 오름차순 정렬 후 상위 5개 표시
- 컬럼: 순위(색상 뱃지), 날짜, 노선, 시간, 교통량, 속도
- 속도 색상 칩:
  - `spd < 40` → 빨간색
  - `40 ≤ spd < 60` → 노란색
  - `spd ≥ 60` → 초록색

---

### 3-5. 교통량 급증 경고 (`aList`)

전 시간 대비 교통량 변화율 `ratio = (cur.vol - prv.vol) / prv.vol`를 계산하여 경고를 생성한다.

| 레벨 | 조건 | 표시 |
|---|---|---|
| `critical` (🔴 급증) | `ratio ≥ 1.0` (+100% 이상) | 빨간 테두리 |
| `warning` (🟡 주의) | `0.5 ≤ ratio < 1.0` (+50~100%) | 노란 테두리 |
| `info` (🔵 혼잡) | `spd < st.cong` AND `vol > 3000` | 파란 테두리 |

- 경고 목록을 `ratio` 내림차순으로 정렬 후 최대 5개 표시
- `prv.vol === 0`인 경우 계산 제외 (division by zero 방지)
- 경고 없으면 "✅ 급증 구간 없음" 메시지 표시

## 4. 데이터 명세

### 원천 데이터 (`RAW`)

- **위치**: `traffic_dashboard.html` 내 `<script>` 블록 line 180
- **크기**: 840개 레코드 (5노선 × 7일 × 24시간)
- **형식**: JavaScript 배열 리터럴 (JSON-like 객체 배열)

```
{ date: string, route: string, hour: number, vol: number, spd: number }
```

| 필드 | 타입 | 범위/값 | 설명 |
|---|---|---|---|
| `date` | string | `"2026-04-01"` ~ `"2026-04-07"` | ISO 날짜 |
| `route` | string | 아래 5개 노선명 중 하나 | 고속도로 노선 |
| `hour` | number | 0 ~ 23 | 시간대 (정수) |
| `vol` | number | 양의 정수 | 시간당 교통량 (대) |
| `spd` | number | 양의 실수 | 평균 속도 (km/h) |

### 노선 목록

```
경부고속도로, 남해고속도로, 서해안고속도로, 영동고속도로, 중부고속도로
```

## 7. 알려진 제약 및 확장 고려사항

| 제약 | 내용 |
|---|---|
| 데이터 고정 | RAW 배열이 하드코딩 → 기간 변경 시 HTML 수정 필요 |
| 오프라인 불가 | Chart.js CDN 의존 → 인트라넷 환경에서 로컬 JS 파일 필요 |
| 단일 노선 비교 | 필터에서 2개 이상 노선 동시 선택 불가 |
| 날짜 범위 | 단일 날짜 또는 전체 7일만 선택 가능, 날짜 범위 슬라이서 없음 |
